# GDD｜RoboPush Arena 遊戲設計規格 v0.2

文件日期：2026-10-24｜狀態：設計草案；P1–P4 已有程式實作，**尚未經 Studio／真機驗證**

## 1. 產品定位

- **類型**：Roblox 休閒多人推落競技（短局、反應與心理戰）。
- **玩家**：MVP 每伺服器 2 位真人（1v1）；待位玩家可看操作提示或打靜態木樁。
- **勝利條件**：利用衝刺或特殊技能製造擊退，讓對手跌出懸浮擂台。
- **核心體驗**：移動與走位 → 誘敵/衝撞 → 反擊/閃避 → 掉落/重生 → 縮圈決勝。
- **設計原則**：一分鐘內上手；相同基礎能力；每局 1 項特殊技能；付費不影響勝負。

## 2. MVP 規則（明確定義）

| 規則 | 設定 |
|---|---|
| 配對人數 | 2（MVP 使用同伺服器等待，不做跨伺服器配對） |
| 倒數 | 3 秒（凍結角色移動和技能） |
| 正式比賽 | 120 秒上限 |
| 勝利目標 | 先得 3 分立即結束 |
| 掉落 | 伺服器判定角色 HumanoidRootPart Y < 8；同次死亡不可重複計分 |
| 計分 | 有效回合中一人掉落且對手存活，對手 +1 |
| 重生 | 掉落後約 2 秒；重生後 1.5 秒免疫擊退 |
| 時間到 | 分數較高者勝；同分進 20 秒 SUDDEN_DEATH |
| 延長賽 | 先掉落者負；仍同分則平手 |
| 離線 | 比賽中玩家離線，另一人獲勝（forfeit），不強制記成 3 分 |
| 雙方同時掉落 | 本回合不計分，雙方重生；延長賽同樣不計分 |
| 局後 | RESULT 顯示結果，再回 WAITING 或新的一局（以實作設定為準） |

**回合釐清：**「掉落得一分」指每次有結果的掉落事件，而不是玩家整場只有一條命。比賽狀態在 RUNNING 時玩家可多次重生得分，並且要防止同一次掉落重複計分。

**公平性**：玩家掉落後直到完成重生不可使用技能；出生保護期間不受攻擊擊退，也不能攻擊對手（避免無敵攻擊）。

**實作釐清（2026-10-24，以 GameConfig 為準）：**

- 出生保護期間 **所有** Dash／特殊技能請求都會被拒絕（含 Counter Shield）。
- RESULT 顯示 `Match.ResultDuration` = 6 秒（暫定），之後若仍有 2 位玩家直接進入下一輪 COUNTDOWN，否則回 WAITING。
- 第 3 位以後加入的玩家排隊（不生成角色）；有參賽者離開時依加入順序補位。
- 一人掉落後，雙掉落窗口（0.1 秒）結束時若對手「存活」才得分；對手正在重生中則不計分。
- 正式賽時間到時，若仍有窗口內未結算的掉落，先結算再判定勝負。
- 冷卻跨重生保留，新一局開始時重設；技能選擇跨局保留（預設 Rocket Pop）。

## 3. 地圖 A：Sky Arena

### 3.1 地形與尺寸

- 單一中央懸浮方形平台，無護欄、無障礙物；初始 48×48 studs。
- 頂面 Y = 20、厚度 2 studs；平台中心固定，X/Z 平面縮放。
- 出生點 A/B 位於中心兩側，初始 X = ±12 studs，Y 依角色站立需求設定。
- 對稱設計、金屬/光滑塑膠材質、Neon 發光邊線；天空/城市背景不影響物理。
- 角色低於 Y = 8 時由伺服器判定掉落；防止重複事件。掉落判定以根節點為準；角色正常離開平台但尚未低於閾值時不立刻計分。

### 3.2 縮圈

| 經過時間（正式賽） | 平台大小 | 備註 |
|---|---|---|
| 0–45 秒 | 48×48 | 正常對戰 |
| 45 秒 | 36×36 | 開始前 5 秒警示 |
| 90 秒 | 24×24 | 開始前 5 秒警示 |
| 120 秒且同分 | 18×18 | 延長賽開始時再縮小 |

- 以 TweenService 改變 Anchored 平台尺寸；每次縮圈動畫建議 2 秒，使用完整碰撞實體。
- 縮圈只在有效比賽狀態進行；比賽結束則停止動畫。
- 每次重生依 **當前** 尺寸重算安全出生點（建議相對中心 ±min(12, size/4) studs），以免出生在平台外。
- 如果比分先達 3 分，無須等待下一次縮圈。

### 3.3 可擴充地圖（非 MVP）

冰面擂台、彈跳平台、旋轉平台、移動障礙物。所有額外機關都應在基礎移動/推力測試後再加。

## 4. 機器人與角色

- 角色以 Roblox **R15 Avatar + Humanoid** 為基底，先貼上外觀裝甲，暫不替換完整 Humanoid/Character Controller。
- **Blue Bot**：藍白裝甲、藍色噴射尾光。
- **Orange Bot**：橘黑裝甲、橘色噴射尾光。
- 兩色**移速、重量、碰撞體、擊退、技能容量完全一致**；外觀差異不得影響 hitbox。
- 建議 WalkSpeed = 16 studs/s；正常跳躍關閉。技能引起的火箭跳、震地跳是特殊移動，不開啟一般跳躍。

## 5. 控制方式

| 行為 | PC | 手機 | 手把 |
|---|---|---|---|
| 移動 | WASD | 左虛擬搖桿 | 左搖桿 |
| 攝影機 | 滑鼠 | 螢幕右側滑動 | 右搖桿 |
| 基本衝刺 | Shift | 右側衝刺按鈕 | RT / R2 |
| 已選特殊技能 | Q | 右側技能按鈕 | LB / L1（暫定） |

- 衝刺與技能方向以 **角色朝向/當前輸入方向** 決定，規則需一致，避免攝影機角度作弊。
- UI 顯示：雙方分數、計時器、Dash 冷卻、特殊技能圖示與冷卻、縮圈警告、開場倒數、結算。
- 手機：按鈕不能與虛擬搖桿重疊；手機真機測試可讀性與誤觸。
- 優先使用 Roblox 支援多裝置的 Input Action System，必要時用 ContextActionService 作相容性替代。

## 6. 戰鬥

### 6.1 固定基本技能：Dash Impact

- 所有角色都能使用；冷卻 4 秒；持續 0.25 秒；衝刺目標速度 40 studs/s。
- 角色前方 120 度範圍、距離不超過 5 studs、高度差合理時才可能命中。
- 同一次 Dash 至多命中一位玩家一次。
- 命中水平擊退目標 42 studs/s，額外向上 12 studs/s；實際需要按組件質量計算 Impulse 並調整物理參數。
- 短暫撞擊閃光/火花/音效/鏡頭震動，視覺與音效 **不得取代** 伺服器命中判定。
- 被強力命中後約 0.4 秒抗擊退保護（待實測）；不可形成無限擊退連鎖。

### 6.2 特殊技能

每局開始前玩家選一項，使用 Q/手機技能鈕/手把映射。七項設計及互相反制請看 [SKILLS.md](SKILLS.md)。首批只做三項：

1. 火箭彈跳 Rocket Pop
2. 側向閃撞 Side Burst
3. 反彈護盾 Counter Shield

其餘：震地重擊、磁力牽引、幻影急煞、緊急錨爪列入後續。

## 7. 比賽狀態機

~~~text
WAITING --2 玩家加入--> COUNTDOWN --3 秒--> RUNNING
RUNNING --一方達 3 分/時間到且不同分/棄權--> RESULT
RUNNING --120 秒到且同分--> SUDDEN_DEATH
SUDDEN_DEATH --第一個有效掉落/20 秒到--> RESULT
RESULT --結算後--> WAITING 或下一輪 COUNTDOWN
~~~

- 只有 RUNNING、SUDDEN_DEATH 才計分；所有計時以伺服器時間為準。
- 若倒數途中玩家離線，回 WAITING。
- 已進 RESULT 後不接受任何晚到的擊退、掉落或計分事件。
- 若兩人同時通過掉落閾值，在同一判定窗口內視為雙掉落；避免更新次序影響公平。
- 斷線、重生、技能 CD 必須解除被中斷的動畫與狀態。

## 8. 美術與音效

視覺方向：鮮明、圓潤玩具感，明確區分雙隊；金屬裝甲但不擬真暴力。打擊回饋：短白閃、動態火花、衝刺尾光、輕微鏡頭震動。縮圈前顯示邊緣警告。首版先用基本幾何體、簡單特效確認玩法；不以高品質 3D 美術卡住 MVP。

## 9. 範圍控制

**MVP 要做**：1 張地圖、2 個對稱機器人外觀、1v1、基本 Dash、三項特殊技能、縮圈、分數、重生、勝負、基本音效、手機 UI。

**MVP 不做**：付費強化、抽卡、跨伺服器 matchmaking、商城、持久化排行榜、複雜物理組裝、多張正式地圖。

## 10. 尚待調校及開放問題

- 多人延遲下命中與推力的公正性；Network Ownership 影響。
- 落地、空中衝刺、推力摩擦是否出現不可控制的連段。
- 反彈護盾的 0.6 秒是否過強；火箭彈跳的突襲前搖。
- 衝刺瞄準方式是否應統一採「角色面向」或「最後移動方向」；第一版建議角色面向。
- 18×18 延長賽的出生點需要足夠緩衝距離。
- 手機 RT/L1 對應只是暫定，需透過真機/手把實驗確定。
