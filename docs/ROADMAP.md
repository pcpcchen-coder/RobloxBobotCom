## 版本目標

- **MVP v0.1**：可以在 Roblox Studio 以 2 位玩家完成一整局的可玩遊戲。
- 先測玩法再做外觀；先有最小化可玩閉環，再增加三項特殊技能。
- 結束條件：測試計畫中的所有 MVP 必測項通過，且已知問題如實記錄。

## P1 — 基礎 Repo、地圖與玩家

**工作**：
- 建立 default.project.json、Luau 專案目錄與同步/執行方式。
- 建立 Sky Arena：48×48 懸浮平台、掉落深度、2 個對稱生成點。
- 在 Studio 使用 R15 Avatar，加藍/橘裝甲外觀，不變更角色碰撞。
- 設定一般跳躍禁用，保留角色正常移動。

**交付**：可打開或由 Rojo 同步的 Roblox Place、雙人可站上平台並移動；README 加入實際運作說明。

**驗收門檻**：同一 Studio Server & Clients 下 2 客戶端連入，可正常移動、站上平台、掉出平台。

## P2 — 1v1 比賽回圈

**工作**：
- MatchService 狀態機 WAITING/COUNTDOWN/RUNNING/SUDDEN_DEATH/RESULT。
- 3 秒倒數、120 秒正式賽、3 分結束、20 秒延長賽及 2 秒重生。
- ScoreService 掉落去重、雙掉落無分、斷線 forfeit。
- 每個 matchId/lifeId 進行事件隔離；HUD 顯示比分與剩餘時間。

**交付**：不用任何技能就能模擬掉落、得分、重生、分勝負。

**驗收門檻**：T01、T02、T05、T06、T09、T13、T14。

## P3 — 衝刺與首批 3 技能

**工作**：
- 基本 Dash：距離/方向/冷卻/連續命中檢查。
- Rocket Pop：起跳衝擊波、短暫空中控制、落地收尾。
- Side Burst：輸入決定側移方向、連續 hitbox 掃描。
- Counter Shield：防禦有效窗口與明確事件優先權。
- UI 技能選擇；簡單粒子、撞擊音效；伺服器拒絕 CD 洗版。
- 重生保護、短暫抗擊退、取消/斷線清理。

**交付**：三個可選特殊技能、固定基本衝刺、可反制的互動。

**驗收門檻**：T03、T04、T11、T15、T16、T17、T18。

## P4 — 縮圈、UI 與跨裝置

**工作**：
- 45 秒 → 36、90 秒 → 24、延長賽 → 18 的平台調整。
- 縮圈前 5 秒提示、縮圈動畫 2 秒、目前尺寸出生點重新計算。
- 完整 UI：倒數、分數、時間、技能 CD、縮圈警示、結算。
- PC Shift/Q、手機兩顆按鈕、手把 RT/L1（依實測確認）輸入。
- 特效/音效初步調整，不引入高成本模型製作。

**交付**：雙端能看見一致狀態，手機可完整遊玩。

**驗收門檻**：T07、T08、T10、T19、T20。

## P5 — 整合、壓測與測試發佈

**工作**：
- Studio 雙客戶端反覆測試，按 TEST_PLAN 實測記錄。
- 有條件測試高延遲情境與手機真機操作。
- 記錄追蹤事件以供錯誤重現；修正雙重計分、掉線競態、打擊不同步。
- README 加入 Roblox Studio 操作/發佈/限制。
- 若可用，私人版本發佈並驗證非開發者帳戶操作。

**交付**：可復現的建置步驟、完整測試證據、發佈狀態、已知限制。

**驗收門檻**：30 場對局無阻礙遊玩的重大 bug；MVP 必測案例全數 Pass 或說明阻塞及降低範圍，不得偽造通過。

## Agent 任務輸出格式

每個階段完成時回報：

1. **實際改動**：檔案、commit/PR、遊戲行為。
2. **驗證方法**：操作步驟、Studio 測試模式、測試帳號/客戶端數量。
3. **證據**：畫面/影片、log、測試案例 Pass/Fail/Blocked。
4. **未完成或風險**：下一步與仍需真人驗證的部分。
5. **下一階段進入條件**：前置階段不應留有會阻塞後續的重大失敗。

不能以「程式碼看起來合理」冒充實際多人測試成功。
