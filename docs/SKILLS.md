# 特殊技能設計與平衡規格 v0.2

狀態：設計初始值；**未實際測試**。原則：好學、可反制、有風險、角色不因付費獲得優勢。

## 0. 共通規則

- 固定基本 Dash Impact：冷卻 4 秒、0.25 秒、速度 40 studs/s，詳見 [GDD](GDD.md)。
- **每場選擇一項特殊技能**（不是同時裝備七項）。特殊技能與 Dash 各自冷卻。
- 倒數、掉落、重生中不可施放；出生保護時禁止造成傷害/擊退。
- 所有技能必須具備：伺服器驗證、有效期間、距離/角度/高度限制、冷卻時間、結束清理及可見反制訊號。
- 控制類效果不得剝奪玩家控制太久；強力擊退命中後預留 ~0.4 秒抗擊退保護（待調校）。
- 若已經落出平台，禁止透過未授權的客戶端位置回報救回角色。
- 每個技能均具有明確特效提示、命中/失敗反饋和 UI 冷卻。

## 2. 火箭彈跳 Rocket Pop（首批）

**意圖**：玩家突然向上彈跳，讓近距離對手措手不及並被起跳衝擊波推出平台；可在空中微調落點。

- 冷卻 **8 秒**。
- 使用時短暫噴射（可見前搖建議 0.15 秒）；向上跳升並保留少量空中橫向控制。
- 起跳瞬間產生半徑 **5 studs** 的近距離擊退（不必依賴角色模型真實觸碰），伺服器判定距離與高度。
- 同次施放只命中每位對手一次；若使用者已在空中，禁止重複施放。
- **反制**：先拉開超過 5 studs，或在對手落地空檔衝刺反擊。
- **主要風險**：跳出平台反而自己掉下去；跳躍不是瞬間無敵。
- **平衡注意**：突襲可以快，但不可完全沒有音效/視覺前搖；初始高度與推力另以多人實測定稿。

## 3. 震地重擊 Ground Slam（後續）

- 冷卻 **10 秒**。短暫跳升，落地時產生 **7 studs** 半徑的圓形震波，向外擊退目標。
- 只有在有效平台上完成落地才能觸發；未落地或掉落則失敗。
- **反制**：見到跳升提示後快速離開震波區；設計明顯落地時間點。
- **風險**：施放期間位置可預判，容易被對手避開並反打。
- **技術注意**：單次落地只觸發一次，不能被反覆觸地事件連續啟動。

## 4. 側向閃撞 Side Burst（首批）

- 冷卻 **7 秒**，選取當前角色面向的左或右側，側移約 **7 studs**；連續動作中的短暫撞擊有效。
- PC 可用 A/D + Q 決定側閃；手機使用虛擬搖桿方向；沒有側向輸入時使用預設右側並於 UI 提示。
- 主要用於避開正面 Dash、繞到敵人側邊撞擊；不提供無敵。
- **反制**：預判側向路線、不要過早 Dash。
- **風險**：靠邊時側移會讓自己掉落；伺服器不替玩家自動防掉落。
- **實作注意**：側移位置不應直接由客戶端指定；以伺服器驗證並施加運動，連續掃描 hitbox 防止穿透。

## 5. 磁力牽引 Magnet Pull（後續）

- 冷卻 **11 秒**，前方 **11 studs** 有效距離，短暫預備後對一名目標施加拉近衝量。
- 前方扇形與高度差限制，目標可以橫向移動躲避；不得無視障礙或將玩家直接 Teleport。
- **反制**：側閃、拉開距離、利用施法前搖。
- **風險**：牽引完讓敵人靠近自己，也可能遭到對方反衝刺。
- 與固定 Dash 可以形成「拉近 → 撞開」連段；需避免過強控制鏈。

## 6. 反彈護盾 Counter Shield（首批）

- 冷卻 **12 秒**，護盾有效 **0.6 秒**，以發光罩顯示防守窗口。
- 只反擊在窗口中**朝自己撞入的有效衝刺/撞擊**，不得持續自動推開附近靜止玩家。
- 反擊方向由伺服器計算，命中後讓主動撞擊者彈開，防守者不受該次擊退。
- **反制**：假動作騙出護盾，等 0.6 秒結束後攻擊。
- **風險**：過早按下會浪費 12 秒 CD。
- **實作注意**：事件順序要固定，避免同幀 Dash/Shield 雙方都被判命中；應有明確 priority。

## 7. 幻影急煞 Phantom Brake（後續）

- 冷卻 **6 秒**；播放衝刺起手動畫但突然停下，留下短暫全息殘影（純視覺）。
- 殘影**不是可被撞擊得分的玩家實體**，不影響真實碰撞。
- **反制**：觀察真正機器人的位置，不追著幻影向平台外衝。
- **風險**：無直接擊退傷害，僅能誘使對手失誤。
- **平衡注意**：即使取消真衝刺，也應消耗此特殊技能 CD；不能無限刷殘影。

## 8. 緊急錨爪 Rescue Claw（後續）

- 冷卻 **15 秒**；當玩家正被推往平台邊緣、尚未正式完成掉落判定時，允許一次邊緣救援。
- 向當前平台**有效**邊緣抓取，拉回平台安全內側；判定必須由伺服器執行，不能讓客戶端選擇任意抓取座標。
- **反制**：等待對方回場後再進攻；對方 CD 很長。
- **風險**：用錯時機無法觸發，且並非可無限復活。
- **實作注意**：當根節點低於 FallHeight、比賽已結束或平台邊緣縮走時不可發動；避免和掉落計分競態。

## 9. 組合與反制循環

1. **基本 Dash → Rocket Pop**：逼近後突然起跳、利用起跳衝擊波推落靠邊對手。
2. **Magnet Pull → Dash**：牽引打亂走位、接著推落（留給未來）。
3. **誘敵靠近 → Counter Shield**：邊緣佯弱反彈衝刺者。
4. **Side Burst → Dash**：從側邊繞開正面對手。

心理戰設計：**正面強攻** 受護盾克制；**防守護盾** 可被假動作與繞側破；**急追** 容易受突跳/急煞牽制。

## 10. 平衡與驗收方法

- 所有參數透過共享 GameConfig 管理；外觀不得改變可命中範圍或推力。
- 每種技能至少記錄：施放次數、命中數、造成擊退、導致掉落、施放者自身掉落、被反制次數。
- 用真實雙人連線及不同延遲情境試驗；保留回合紀錄（時間、技能、位置、狀態、結果）。
- 檢查出生保護、CD 洗版、多次命中、技能被中斷、平台縮圈和延長賽下的邊界狀況。
- 指標不是「平均勝率剛好相同」即宣稱平衡，而是確認每招有反制機會，且沒有無條件必中/無限連擊。

> 遊戲 MVP **只實作三項首批技能**；七項完整設計均列入產品規格，不代表已做完。
